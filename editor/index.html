Wave Definitions

Custom waves replace the game's built-in waves for this level. Difficulty tabs add extra sets on top: a level played on EASY uses the Easy tab's waves, and an empty difficulty tab inherits the Default tab (which falls back to the game's built-ins). Spawn ms = delay between spawns of an entry; wave ms = delay before the entry starts. path = turns at each split (e.g. 0,1, empty = random); spawn = spawn point index (empty = random).
